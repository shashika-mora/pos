## How to Build & Run

```
# Compile (from project root)
javac SuperSaverPOSGroup_BinaryMinds.java

# Run
java SuperSaverPOSGroup_BinaryMinds
```

Ensure `products.csv` is in the same directory as the compiled class.  
The program will auto-create `pending_bills/` and `bills/` folders on first run.
